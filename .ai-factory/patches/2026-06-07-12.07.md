# Factory UX fixes

## Scope

- `diaweb`: factory upgrade dialog, requirement navigation, production toasts, warehouse/early-access copy, focused factory tests.
- `diaverseapi`: factory state service compartment action guards and focused state-service tests.

## Changes

- Reset upgrade mutation UI state when the upgrade dialog opens/closes, so repeated upgrades do not require leaving the menu.
- Show the real target level in upgrade success copy, including package upgrades to level 5.
- Require an explicit factory-level payment choice between game dollars and bricks before submitting.
- Keep the factory-level modal close button visible on small screens.
- Make factory-level requirement rows link to the relevant workshop or compartment.
- Localize factory requirement labels with catalog display helpers.
- Suppress already auto-dismissed state toasts during the current frontend session.
- Reword warehouse stopped status so it describes a paused warehouse item, not all workshops.
- Add the factory level where early-access conditions become normal.
- Hide compartment upgrade action when the compartment is already max level or the production part is inactive.
