# Advent Mockup Skin Card Border Fix

**Date:** 2026-04-23 15:55
**Files:** diaweb/frontend/mockups/advent-desktop/index.tailwind.html
**Severity:** low

## Problem

Pilot and pet skin cards in the static Advent shop mockup showed an extra visual border/footer treatment because the skin reference image already contained the card chrome while the HTML article also drew its own border and shadow. Opening overlays also removed the page's vertical scroll.

## Root Cause

The skin cards are currently represented by dedicated full-card reference assets. Applying the generic article border/shadow on top of those assets produced a doubled card edge and made the DCR footer look inset. The overlay state used `overflow: hidden` on `body`, which disabled page scrolling.

## Solution

Kept the skin card reference assets as the single skin-card visual source and disabled the additional outer border/shadow for `skin-card--pilot` and `skin-card--pet`. Changed `body.has-overlay` to preserve vertical scrolling while keeping horizontal overflow contained.

## Prevention

When a mockup card uses a full-card reference asset that already includes chrome, do not also apply a generic card border/shadow. For overlays in scrollable mockups, avoid body-level vertical scroll locks unless the design explicitly calls for them.
