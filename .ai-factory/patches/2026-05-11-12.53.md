# Shop Admin Catalog Price And Soft Delete Fix

## Summary

- Fixed staff shop catalog bulk-add so explicit USDT prices create provider offers instead of leaving listings without a visible price.
- Added soft-delete semantics for admin shop items through metadata markers; deleted rows and their offers are disabled but kept in the database.
- Hid soft-deleted shop items from admin listing and catalog sync preview.
- Allowed re-adding a soft-deleted catalog item by restoring the existing row and updating the default provider offer price.
- Changed the staff shop table action from disable-only behavior to a visible delete action.
