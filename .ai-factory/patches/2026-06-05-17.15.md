# Factory desktop recipe and map spacing visual fix

**Date:** 2026-06-05 17:15
**Files:** diaweb/frontend/modules/factory/components/CompartmentScreen.tsx, diaweb/frontend/modules/factory/assetManifest.ts
**Severity:** low

## Problem

The life force compartment recipe looked correct on mobile but became cramped on desktop because the input and output sections were forced into a horizontal three-column grid. The main factory map also placed the lower workshop row too close to the bottom edge.

## Root Cause

The recipe layout assumed desktop width should always become a left-to-right flow, but long resource lists need full-width rows. The factory map hotspot layout used fixed percentage Y coordinates with large gaps in the lower half, pushing late rows down even when the viewport already cropped the map.

## Solution

Changed the recipe block to a single vertical grid for all breakpoints and replaced the horizontal arrow with a vertical divider. Tightened the hotspot Y coordinates so workshop rows sit closer together, with lower rows moved upward more than the top rows.

## Prevention

Review factory visual layouts at both mobile and desktop breakpoints when resource lists can grow. Prefer full-width stacked rows for variable-length production recipes, and keep fixed map coordinates tested against the actual viewport crop.
