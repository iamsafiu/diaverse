# Advent paid cell modal preserves page scroll

**Date:** 2026-04-25 11:31
**Files:** `diaweb/frontend/modules/advent/components/AdventCellModal.tsx`, `diaweb/frontend/__tests__/modules/advent/AdventCellModal.test.tsx`
**Severity:** medium

## Problem

Opening a paid Advent calendar cell showed the payment modal, but the document scroll was disabled. On constrained screens this could make it impossible to reach the payment button.

## Root Cause

`AdventCellModal` used the common modal scroll-lock pattern and set `document.body.style.overflow = "hidden"` while open. That assumption did not fit this Advent flow because the payment modal can be taller than the visible viewport and the user must be able to keep scrolling to reach the checkout CTA.

## Solution

Removed the body overflow mutation from `AdventCellModal` while keeping the Escape key close handler. The existing modal-open debug log now records that scroll lock is preserved, and a regression test asserts that opening and unmounting the paid cell modal leaves `document.body.style.overflow` unchanged.

## Prevention

For tall cabinet modals with critical actions near the bottom, avoid global body scroll locking unless the modal content has a verified accessible internal scroll area on mobile and desktop. Add regression tests around body overflow behavior for payment and checkout CTAs.
