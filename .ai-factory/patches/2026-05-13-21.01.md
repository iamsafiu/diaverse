# Cabinet main shell blur artifacts

**Date:** 2026-05-13 21:01
**Files:** diaweb/frontend/modules/cabinet/components/CabinetLayout.tsx
**Severity:** medium

## Problem

After the first overlay cleanup, browser-dependent artifacts were still visible inside the cabinet `main` panel, especially around the shared panel class used by profile, shop, and advent pages.

## Root Cause

The shared `main` shell applied a large `backdrop-blur-[20px]` directly to a rounded, clipped, scroll-adjacent panel with inset shadows. In Chrome this can force expensive backdrop-filter compositing and leave stale rectangular paint artifacts while scrolling. The shell also did not explicitly isolate child blend and z-index layers from the rest of the page.

## Solution

Removed the backdrop blur from the shared `main` shell and added `isolate` to keep internal blend/absolute layers contained. The fix intentionally left layout-affecting classes unchanged: size, padding, margins, border, radius, background, shadows, and overflow remain the same.

## Prevention

- Avoid applying large backdrop filters directly to primary scroll panels.
- Prefer normal translucent backgrounds for large shell surfaces; keep backdrop filters on smaller controls only.
- Add `isolation: isolate` on shared shell containers that host complex absolute, blend, or z-index children.
- When fixing visual artifacts, preserve layout classes separately from compositor-related classes.
