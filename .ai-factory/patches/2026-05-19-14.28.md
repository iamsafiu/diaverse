# Missing copywriting image settings migration on server

**Date:** 2026-05-19 14:28
**Files:** production database, aibot/migrations/20260519_0003_copywriting_club_image_style.sql
**Severity:** high

## Problem

After clicking regenerate in copywriting sections, the page showed "This page couldn't load". Frontend logs only showed BFF failures for `/image-settings/active`; aibot logs showed PostgreSQL `UndefinedColumnError` for `copywriting_image_settings.club_image_style_text`.

## Root Cause

The deployed application code expected the new club image style column, but the production copywriting database had not applied `20260519_0003_copywriting_club_image_style.sql`.

## Solution

Applied the idempotent migration SQL on the copywriting database:

`ALTER TABLE copywriting_image_settings ADD COLUMN IF NOT EXISTS club_image_style_text TEXT NOT NULL DEFAULT '';`

Then verified `GET /internal/v1/image-settings/active` through `diaweb-dev` service JWT returned HTTP 200.

## Prevention

When deploying aibot changes with model/schema additions, apply migrations before restarting API/worker runtimes and smoke-test the affected BFF endpoints.
