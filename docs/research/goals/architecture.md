# Architecture Goal Notes

Общий принцип
Единая платформа с одним личным кабинетом. У каждого пользователя — свой набор доступных модулей, который определяется через галочки в админ-панели. Галочки могут ставиться вручную или автоматически (например, в зависимости от наличия подписки), а так же пресетами.

UI: левая панель с вертикальным меню, центральная часть — содержимое раздела. Набор пунктов меню формируется динамически по доступам.

Модули партнёра
Раскрывающееся меню - “Партнерсво”. Может добавлено пользователю в ЛК или скрыто Администраторами с соответствующими правами в админ-панели.

Список партнёров: кого пригласил, статусы (активный / неактивный), кто оплатил / нет

Доходы: заработано / выплачено

Инструменты: контент-завод, автопостинг в соцсети, AI-агенты, калькулятор дохода, маркетинговые материалы, обучение

Кабинет сотрудника
Раскрывающееся меню - “Кабинет сотрудника”. Может добавлено пользователю в ЛК или скрыто Администраторами с соответствующими правами в админ-панели.

Каждый модуль также может быть добавлен или скрыт в админ-панели, в зависимости от уровня доступа сотрудника и его функционала

Модуль 1 — Логирование
Логирование всех действий всех пользователей. ТЗ готово (написано ~2 месяца назад, лежит в Confluence).

Модуль 2 — Основная админ-панель (управление игрой)
Управление предметами, банами, начислениями и т.п. Аналог текущей админки — переносится и расширяется.

Модуль 3 — Саппорт
Сотрудник заходит по своему логину, видит интерфейс саппорта. Детальное описание функций уже есть в Confluence (написано ~3–4 месяца назад).

⚠️ Приоритет: если Telegram заблокируют в России, текущий саппорт через Telegram-бота станет недоступен. Перенос саппорта на сайт — срочная задача.

Уровни внутри модуля саппорта:

Младший сотрудник — ограниченный набор функций

Старший - шире

Начальник саппорта — максимальный доступ

Модуль 4 — Биржа (админка)
Сама биржа находится в приложении. В кабинете сотрудника — только админка биржи.

Админ биржи — полный доступ: отменять / выставлять ставки, любые операции. Галочка стоит у сотрудников саппорта нужного уровня

Модуль 5 — Метрики и дашборды
DAU, MAU, Retention и другие показатели

Финансовые дашборды (не таблицы — именно дашборды)

по структуре:
Смотри, по структуре.
Делаем 2 разных интерфейса:

- для пользователей и партнеров
- для сотрудников и админа

Мобильная версия для пользователей:
Для пользователей игровой дизайн. По структуре предлагаю такое: на мобилке снизу будет меню, в котором будет закреплено слева направо: офферы, магазин, партнерка, профиль в виде иконок. Остальные модули будут располагаться в профиле - там по сути будет список модулей(статистика, питомцы и так далее).

Десктопная версия для пользователей - пока неизвестно.

Для сотрудников оставляем текущую реализацю на мобилке и на десктопе(слева меню, справа содержимое на десктопе; бургер меню справа и меню на полный экран на мобилке).
