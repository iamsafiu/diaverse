# Shop Recommended Notes

Пара небольших рекомендаций для Phase 1 (до перехода на фасад):

Обработка частичных отказов: В Phase 1 ты используешь Promise.all для запросов к /market, /characters/store и т.д. Убедись, что падение одного некритичного сервиса (например, сервиса питомцев) не «положит» весь магазин. Лучше использовать Promise.allSettled и рендерить каталог из того, что удалось загрузить.

Строгая валидация (опционально): Поскольку в Phase 1 фронт собирает данные из разных мест, использование библиотек вроде Zod внутри функции normalize поможет гарантировать, что собранный ShopCatalog строго соответствует заявленным типам (особенно это касается полей locked и metadata).
