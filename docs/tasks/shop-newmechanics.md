# Shop New Mechanics Task Brief

1. ЭВОЛЮЦИИ ПЕТОВ — РАСШИРЕНИЕ

В разделе Пэты необходимо добавить возможность создавать лоты не только первой эволюции, но и любой другой — второй, третьей, четвёртой, пятой, шестой и так далее без ограничений.

━━━━━━━━━━━━━━━━━━━━━

2. РАЗДЕЛЬНОЕ УПРАВЛЕНИЕ ВИДИМОСТЬЮ ЛОТА

Для каждого лота нужно реализовать две независимые галочки:

• ☑️ Магазин — лот отображается в общей сетке магазина

• ☑️ Спецпредложение — лот попадает в рандомайзер, который формирует блок из 6 спецпредложений в шапке

Логика работы:

1. Галочка «Магазин» ✅ / Галочка «Спецпредложение» ❌ → Лот виден в магазине, но не участвует в рандомайзере

2. Галочка «Магазин» ❌ / Галочка «Спецпредложение» ✅ → Лот скрыт из общей сетки, но участвует в рандомайзере

Рандомайзер крутит не всё подряд, а только лоты с явно выставленной галочкой.

━━━━━━━━━━━━━━━━━━━━━

3. БАНДЛЫ — НОВАЯ СУЩНОСТЬ

Функционал доступен во всех разделах, не только в Пэтах.

Что такое бандл:

Набор из нескольких произвольных лотов, объединённых в один товар. Количество позиций — неограничено.

Пример состава:

• 200 капсул опыта • 2 пэта третьей эволюции • XDV 100 000

Управление бандлом — те же две галочки:

• ☑️ Магазин — бандл в общем пуле товаров магазина • ☑️ Спецпредложение — бандл в ротации из 6 офферов в шапке

Галочки независимы: скрыть из магазина, но пустить в спецпредложения — и наоборот.
