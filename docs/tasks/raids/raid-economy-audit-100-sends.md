# Аудит экономики рейдов на 100 отправок

Дата: 2026-06-03

Backend-снимок: `diaverseapi/dev`, коммит `a21ab314 fix(raids): increase cave acorn rewards`.

## Цель

Пересчитать экономику рейдов по текущему backend после правки Ядерной пещеры:

```text
nuclear_acorn в radioactive_cave: 2-4 -> 8-16
```

Проверяем, как теперь выглядит желаемая лестница:

```text
Оазис выгоднее Ржавых пустошей на 10%
Ядерная пещера выгоднее Оазиса на 10%
```

Важно: расчет сделан по текущему backend-коду и backend-каталогу, а не по ТЗ.

## Что изучалось

- `diaverseapi/app/raids/catalog/data/raids_catalog.v1.yaml` - текущие цены, XP, ресурсы, шкатулки, особый лут, pet abilities.
- `diaverseapi/app/raids/domain/pricing.py` - расчет цены входа.
- `diaverseapi/app/raids/domain/rewards.py` - XP, ресурсы, шкатулки, crit, special loot.
- `diaverseapi/app/raids/domain/streaks.py` - серия локации.
- `diaverseapi/app/raids/domain/traps.py` - ловушки, иммунитет, выкуп.

## Метод расчета

Базовый сценарий:

- 100 последовательных отправок в один биом.
- Режим: `basic_xdv`.
- 1 пет на рейд.
- Пет подходящей редкости.
- Обычный пет без biome ability, если явно не указано другое.
- Старт серии: 0%.
- Скидка Оазиса по текущему backend отключена: `increment_percent = 0`, `max_discount_percent = 0`.
- Считается expected value, не случайная симуляция.

Backend-особенности:

- серия применяется к ресурсам и шансу шкатулок;
- ресурсы округляются на каждой выдаче через `ROUND_HALF_UP`;
- crit шкатулки удваивает количество выпавшей шкатулки;
- matching rarity дает `+50% XP`, но не увеличивает ресурсы;
- special loot считается отдельно от ресурсов и шкатулок.

Для rough-score шкатулок используется proxy-модель:

```text
basic = 1
uncommon = 2
rare = 5
epic = 15
legendary = 50
```

Это не официальный курс ценности. Это техническая proxy-метрика, чтобы сравнить шкатулки одной цифрой.

## Главные выводы

### Ржавые пустоши

- Лучший источник патронов.
- Очень сильный special loot: 50 ожидаемых slot_token за 100 basic_xdv рейдов.
- По chest ROI уступает Оазису и Пещере.

### Оазис

- Лучший источник галаклея.
- По шкатулкам на XDV стабильно лучше Пустошей.
- После отключения скидки перестал быть чрезмерно дешевым.
- По XP с учетом ловушек хуже Пустошей, потому что XP/XDV одинаковый, а trap risk выше.

### Ядерная пещера

- Теперь главный источник ядерных желудей с большим запасом.
- По ядерным желудям на XDV сильно выгоднее Оазиса.
- По шкатулкам на цену входа проходит цель `+10%` против Оазиса.
- По шкатулкам с учетом expected trap liability не проходит цель `+10%`.
- По XP на XDV не становится выгоднее, потому что XP-лестница пропорциональна цене.

## Финальный вердикт

Правка `nuclear_acorn 8-16` успешно усилила роль Ядерной пещеры как источника ядерных желудей.

Если экономика должна оцениваться по специализированному ресурсу:

```text
Пещера как источник ядерных желудей теперь сильно выгоднее Оазиса.
```

Если экономика должна оцениваться по proxy-score шкатулок:

```text
Пещера лучше Оазиса на +11.35% по чистому входу.
Пещера лучше Оазиса только на +2.86% с учетом expected ловушек.
```

Если экономика должна оцениваться по XP:

```text
Лестницы +10% нет. XP/XDV одинаковый по чистому входу и хуже у рискованных биомов после учета ловушек.
```

Итог: текущий backend уже хорошо закрепляет специализацию биомов, но универсальная ROI-лестница `Пустоши -> Оазис -> Пещера` выполняется не по всем метрикам. Чтобы Пещера была на `+10%` выгоднее Оазиса именно с учетом ловушек по chest score, нужно еще примерно `+6.9%` к ее chest-score ценности или эквивалентное снижение цены/риска.
