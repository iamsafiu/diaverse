# Рейды "Путь к приключениям" - игровой сценарий и механика

[Back to Docs](../../README.md)

Этот документ объясняет рейды не как таблицу формул, а как игровой опыт: что видит игрок, какие решения принимает, как связаны экранная структура, пэты, локации, режимы, стрики, награды и ловушки.

Основная спецификация с точными таблицами живет в [raids-mechanics.md](raids-mechanics.md). Этот файл нужен для продуктового, UX и дизайн-разбора.

## Короткая Суть

Рейды - это походы пэтов в одну из трех локаций: базовый XDV и USDT длятся 24 часа, XDV с подпиской длится 12 часов.

Игрок:

1. Открывает экран рейдов.
2. Видит большую мобильную рейдовую карту.
3. Выбирает локацию.
4. Выбирает режим: базовый XDV, XDV с подпиской или USDT.
5. Выбирает свободный слот.
6. Выбирает пэта.
7. Подтверждает цену и риск.
8. Ждет завершения рейда.
9. Получает XP, ресурсы, шкатулки и особый лут.
10. Если пэт попал в ловушку, выкупает его или отправляет спасателя.

В одном предложении: **рейды - это ежедневная система отправки пэтов на рискованный фарм ресурсов, где правильная локация, редкость пэта, режим доступа и серия повторных отправок заметно меняют итоговую выгоду.**

## Главная Игровая Петля

```text
+-----------------------+
| открыть рейдовую карту |
+-----------+-----------+
            |
            v
+-----------------------+
| выбрать локацию       |
+-----------+-----------+
            |
            v
+-----------------------+
| выбрать режим рейда   |
+-----------+-----------+
            |
            v
+-----------------------+
| выбрать слот и пэта   |
+-----------+-----------+
            |
            v
+-----------------------+
| подтвердить отправку  |
+-----------+-----------+
            |
            v
+-----------------------+
| рейд идет 24/12 часов |
+-----------+-----------+
            |
            v
   +--------+---------+
   |                  |
   v                  v
+---------+      +---------+
| награды |      | ловушка |
+----+----+      +----+----+
     |                |
     v                v
+---------+      +---------+
| повтор  |      | выкуп / |
| рейда   |      | спасение|
+---------+      +---------+
```

Главная петля должна быть понятна без чтения формул. Формулы нужны для деталей, но игрок должен интуитивно понимать:

- куда выгодно отправить конкретного пэта;
- сколько это стоит;
- какой риск;
- что он может получить;
- что произойдет после завершения таймера;
- чем опасна ловушка;
- почему выгодно повторять одну и ту же локацию.

## Базовая Экранная Структура

Рейды проектируются как мобильный полноэкранный экран 9:16. Центр экрана занимает большая вертикальная рейдовая карта.

```text
+--------------------------------+
| XDV | USDT | игровые доллары | |
+--------------------------------+
|                                |
|          РЕЙДОВАЯ КАРТА        |
|                                |
|  [Ржавые Пустоши]              |
|                                |
|  [Оазис]                       |
|                                |
|  [Радиоактивная Пещера]        |
|                                |
+--------------------------------+
| нижняя навигация приложения    |
+--------------------------------+
```

В шапке первого макета не показываем DCR. Проект пока не перешел на DCR, поэтому DCR не должен появляться в HUD, пользовательских текстах и механике рейдов.

В HUD показываем:

- XDV;
- USDT;
- игровые доллары;
- уведомления;
- статус подписки, если нужен компактный индикатор.

Важно: игровые доллары в HUD — только общий баланс приложения. Они не оплачивают рейды, не выпадают в наградах и не определяют слот-лимит. Слот-лимит рейдов показывается как количество доступных слотов, а не как DCR или игровая валюта.

## Экран 1: Главная Рейдовая Карта

На главной карте игрок видит три локации. Это не детальная таблица. Это экран выбора направления.

```text
+--------------------------------+
| XDV 12 450   USDT 18.5    bell |
| $ 84 200                crown  |
+--------------------------------+
|                                |
|          РЕЙДОВАЯ КАРТА        |
|                                |
| +----------------------------+ |
| | РЖАВЫЕ ПУСТОШИ             | |
| | +70% стрик    ловушка 5%   | |
| | 200 XDV       [пэт][+]     | |
| +----------------------------+ |
|                                |
| +----------------------------+ |
| | ОАЗИС                      | |
| | +35% стрик    ловушка 10%  | |
| | 400/800 XDV   [пэт][пэт]   | |
| +----------------------------+ |
|                                |
| +----------------------------+ |
| | РАДИОАКТИВНАЯ ПЕЩЕРА       | |
| | +12% стрик    ловушка 20%  | |
| | 800/2400 XDV  [+]          | |
| +----------------------------+ |
|                                |
+--------------------------------+
| Магазин  Фабрика  Рейды  Проф |
+--------------------------------+
```

На свернутой карточке достаточно показывать:

- название локации;
- текущий стрик;
- базовый риск ловушки;
- короткую цену XDV;
- мини-иконки пэтов, которые уже там;
- признак ловушки, если в этой локации есть застрявший пэт.

Не нужно показывать все шансы и все режимы на свернутой карточке. Это перегрузит экран.

## Экран 2: Раскрытая Локация

После нажатия локация раскрывается и становится рабочей областью.

```text
+--------------------------------+
| XDV 12 450   USDT 18.5    bell |
| $ 84 200                crown  |
+--------------------------------+
| ОАЗИС                    +35%  |
|                                |
| Режим рейда:                   |
| [Базовый] [Подписка] [USDT]    |
|                                |
| Шкатулки:                      |
| Базовая       60% -> 81%       |
| Необычная     40% -> 54%       |
| Редкая        20% -> 27%       |
| Эпическая     10% -> 13.5%     |
|                                |
| Опасность:                     |
| Ловушка 10%       Крит 25%     |
|                                |
| Слоты:                         |
| +----------+  +----------+     |
| | пэт      |  | +        |     |
| | 12ч      |  | выбрать  |     |
| +----------+  +----------+     |
| +----------+  +----------+     |
| | +        |  | +        |     |
| +----------+  +----------+     |
|                                |
| Ржавые Пустоши                 |
| Радиоактивная Пещера           |
+--------------------------------+
```

Раскрытая локация отвечает на вопросы:

- сколько стоит отправка;
- какой режим выбран;
- какие шансы шкатулок сейчас;
- какой риск ловушки;
- есть ли крит шкатулки;
- сколько слотов доступно;
- какие пэты уже в рейде;
- какие пэты застряли.

Остальные две локации можно оставить снизу короткими полосками. Они нужны для быстрого переключения, но не должны отнимать фокус у выбранной локации.

## Экран 3: Выбор Пэта

Игрок нажимает пустой слот. Снизу открывается шторка.

```text
+--------------------------------+
| ОАЗИС                    +35%  |
|                                |
| [параметры затемнены]          |
|                                |
+--------------------------------+
|          ВЫБРАТЬ ПЭТА          |
| [Редкие] [Эпические] [Легенд.] |
|                                |
| +----------------------------+ |
| | Тушканчик          800 XDV | |
| | доступен          бонус x3 | |
| +----------------------------+ |
| +----------------------------+ |
| | Капибара           400 XDV | |
| | доступен       подходит ok | |
| +----------------------------+ |
| +----------------------------+ |
| | Барсук             800 XDV | |
| | в другом рейде             | |
| +----------------------------+ |
|                                |
| [Отмена]                       |
+--------------------------------+
```

Карточка пэта должна показывать:

- аватар;
- имя;
- редкость;
- цену входа именно в текущую локацию;
- доступность;
- бонус, если пэт подходит локации;
- спецспособность, если она работает в этой локации.

Цена должна быть уже пересчитана. Игрок не должен считать сам, почему редкий пэт в Пещере стоит 2400 XDV, а легендарный 800 XDV.

## Экран 4: Подтверждение Отправки

После выбора пэта игрок видит короткое подтверждение.

```text
+--------------------------------+
| Отправить Капибару в Оазис?    |
|                                |
| Режим: Базовый XDV             |
| Цена: 400 XDV                  |
| Длительность: 24 часа          |
| Ловушка: 10%                   |
| Крит шкатулки: 25%             |
|                                |
| [Отправить]                    |
| [Отмена]                       |
+--------------------------------+
```

Это место должно защищать от случайной отправки. Если отправка сбросит стрик другой локации, здесь нужен явный warning:

```text
Внимание: отправка в Оазис сбросит стрик Ржавых Пустошей +70%.
```

Если выбран USDT-режим, подтверждение должно показывать:

- цену в USDT;
- ловушку 0%;
- XP x5;
- шансы шкатулок x4;
- отсутствие лимита слотов;
- отсутствие спеша.

Если выбран XDV-рейд с подпиской, подтверждение должно показывать `Длительность: 12 часов` и индикатор `ускорение x2`, но не отдельную кнопку ускорения.

## Экран 5: Активный Рейд

После отправки слот становится занятым.

```text
+--------------------------------+
| ОАЗИС                    +35%  |
|                                |
| Слоты:                         |
| +----------------+ +--------+  |
| | Капибара       | | +      |  |
| | 12ч 18м        | | выбрать|  |
| | progress bar   | +--------+  |
| | ускорение x2   |             |
| +----------------+             |
|                                |
+--------------------------------+
```

Слот активного рейда показывает:

- пэта;
- локацию, если слот отображается вне раскрытой локации;
- оставшееся время;
- прогресс;
- режим рейда;
- индикатор `ускорение x2`, если это XDV-рейд с подпиской.

Базовый XDV-рейд и USDT-рейд длятся 24 часа. XDV-рейд с подпиской длится 12 часов: это автоматический бонус, а не отдельная кнопка. После завершения пэт не должен автоматически уходить в новый рейд. Игрок вручную забирает награды и может нажать `Повторить рейд`.

## Экран 6: Итоги Рейда

После завершения рейда игрок получает модальное окно итогов.

```text
+--------------------------------+
|          РЕЙД ЗАВЕРШЕН         |
+--------------------------------+
| Капибара вернулась из Оазиса   |
|                                |
| XP                             |
| +750 XP                        |
|                                |
| Ресурсы                        |
| Галаклеи             18        |
| Патроны              2         |
| Желуди               1         |
|                                |
| Шкатулки                       |
| [Базовая] [Редкая]             |
| CRIT x2                        |
|                                |
| Особый лут                     |
| Ядро синтеза         1         |
| Токен слота          0         |
|                                |
| [Забрать]                      |
| [Повторить рейд]               |
+--------------------------------+
```

Итоги должны объяснять не только "что выпало", но и "почему столько":

- XP с бонусом редкости и режима;
- ресурсы с учетом стрика;
- шкатулки с итоговыми шансами;
- крит, если сработал;
- особый лут, даже если выпало 0;
- кнопка повторного запуска.

Полезная подача для ресурсов:

```text
Галаклеи: 12 x 1.5 стрик = 18
```

Полезная подача для шкатулок:

```text
Базовая: 60% x 1.35 стрик = 81%
```

## Экран 7: Ловушка

Ловушка - это кризисный state. Он должен выглядеть иначе, чем обычный рейд.

```text
+--------------------------------+
| ОАЗИС                ЛОВУШКА   |
+--------------------------------+
|                                |
| +----------------------------+ |
| | Капибара заблокирована     | |
| | Осталось: 6д 23ч 59м       | |
| |                            | |
| | Выкуп: 1200 XDV            | |
| |                            | |
| | [Выкупить за 1200 XDV]     | |
| | [Отправить спасателя 50%]  | |
| +----------------------------+ |
|                                |
+--------------------------------+
```

Игрок должен сразу понять:

- пэт еще жив;
- время ограничено 7 днями;
- после таймера пэт пропадет;
- можно выкупить за XDV;
- можно рискнуть спасателем;
- спасатель при провале тоже будет заблокирован.

## Экран 8: Спасатель

Спасение открывает отдельную шторку выбора пэта.

```text
+--------------------------------+
| ОТПРАВИТЬ СПАСАТЕЛЯ            |
|                                |
| Шанс успеха: 50%               |
| При провале спасатель тоже     |
| попадет в ловушку.             |
|                                |
| +----------------------------+ |
| | Тушканчик          800 XDV | |
| | выкуп при провале: 2400    | |
| +----------------------------+ |
| +----------------------------+ |
| | Барсук             800 XDV | |
| | выкуп при провале: 2400    | |
| +----------------------------+ |
|                                |
| [Отмена]                       |
+--------------------------------+
```

Главное правило спасателя: его возможный выкуп считается по собственной цене входа спасателя в этой локации, а не по цене спасаемого пэта.

## Локации

### Ржавые Пустоши

Роль: безопасная и дешевая локация для регулярного фарма.

Ключевые числа:

| Параметр | Значение |
| --- | ---: |
| Цена XDV | 200 для всех пэтов |
| Цена USDT | 4 |
| Базовый XP | 250 |
| Подходящая редкость | Редкий пэт |
| Бонус подходящей редкости | +50% XP |
| Стрик | +1% за отправку, максимум +70% |
| Ловушка без подписки | 5% |
| Ловушка с подпиской | 0% |
| Ловушка USDT | 0% |
| Крит шкатулки | 50% |
| Главный ресурс | Патроны |
| Особый лут | Ядро синтеза, Токен слота |

Почему игрок выбирает Пустоши:

- низкая цена;
- почти нет риска;
- максимальный стрик среди всех локаций;
- высокий крит шкатулки;
- единственный источник Токенов слота;
- хорошая зона для редких пэтов.

UX-сигнал: Пустоши должны выглядеть как "стабильный фарм". Цвет - янтарный, ржавый, песочный.

### Оазис

Роль: средняя локация для эпических пэтов и фарма Галаклеев.

Ключевые числа:

| Параметр | Значение |
| --- | ---: |
| Цена XDV для эпического пэта | 400 |
| Цена XDV для остальных | 800 |
| Цена USDT | 8 |
| Базовый XP | 500 |
| Подходящая редкость | Эпический пэт |
| Бонус подходящей редкости | +50% XP |
| Стрик | +1% за отправку, максимум +50% |
| Ловушка без подписки | 10% |
| Ловушка с подпиской | 5% |
| Ловушка USDT | 0% |
| Крит шкатулки | 25% |
| Главный ресурс | Галаклеи |
| Особый лут | Ядро синтеза |

Отдельная механика: скидка регулярности.

- Каждый следующий XDV-рейд в Оазис дешевле на 5%.
- Минимум - 50% от исходной цены.
- Сброс - через 7 дней после автоматического завершения последнего рейда, если игрок не запустил новый рейд в Оазис.

UX-сигнал: Оазис должен выглядеть как "эффективный регулярный маршрут". Цвет - бирюзовый, изумрудный, вода, энергия.

### Радиоактивная Пещера

Роль: дорогая и опасная high-risk локация для легендарных пэтов.

Ключевые числа:

| Параметр | Значение |
| --- | ---: |
| Цена XDV для легендарного пэта | 800 |
| Цена XDV для остальных | 2400 |
| Цена USDT | 12 |
| Базовый XP | 1000 |
| Подходящая редкость | Легендарный пэт |
| Бонус подходящей редкости | +50% XP |
| Стрик | +1% за отправку, максимум +30% |
| Ловушка без подписки | 20% |
| Ловушка с подпиской | 10% |
| Ловушка USDT | 0% |
| Крит шкатулки | Нет |
| Главный ресурс | Радиоактивные Желуди |
| Особый лут | Нет |

Почему игрок выбирает Пещеру:

- самый высокий XP;
- единственный источник Радиоактивных Желудей;
- лучшие шансы редких и эпических шкатулок;
- единственный шанс легендарной шкатулки.

UX-сигнал: Пещера должна выглядеть как "дорого, опасно, но сильно". Цвет - кислотно-зеленый с вторичным фиолетовым.

## Режимы Доступа

### Базовый XDV

Это стандартный режим.

Игрок получает:

- базовый XP;
- базовые шансы шкатулок;
- обычные ресурсы;
- шанс особого лута, если он есть в локации;
- риск ловушки по ставке локации.

Игрок не получает:

- бонус подписки;
- спеш;
- защиту USDT от ловушек.

### XDV С Подпиской

Это усиленный XDV-режим.

Подписка дает:

- XP x2;
- шансы шкатулок x2;
- больше слотов;
- автоматическое ускорение рейда до 12 часов;
- снижение ловушек;
- больше Ядер синтеза и Токенов слота там, где они вообще могут выпасть.

Подписка не дает:

- скидку на XDV-вход;
- усиление стрика;
- влияние на USDT-рейды.

### USDT

Это premium-режим без ловушек.

USDT дает:

- XP x5;
- шансы шкатулок x4;
- больше новых ресурсов там, где они доступны;
- ловушки 0%;
- слоты без лимита.

USDT не дает:

- спеш;
- дополнительное влияние подписки;
- усиление кумулятивного эффекта.

## Пэты И Редкость

Редкость пэта влияет на два главных параметра:

- цену входа;
- бонус XP, если пэт подходит локации.

Матрица:

| Пэт | Пустоши | Оазис | Пещера |
| --- | --- | --- | --- |
| Редкий | +50% XP, 200 XDV | 800 XDV | 2400 XDV |
| Эпический | 200 XDV | +50% XP, 400 XDV | 2400 XDV |
| Легендарный | 200 XDV | 800 XDV | +50% XP, 800 XDV |

Простое объяснение для игрока:

- редкого выгодно вести в Пустоши;
- эпического выгодно вести в Оазис;
- легендарного выгодно вести в Пещеру;
- можно отправить любого пэта куда угодно, но неподходящий пэт часто стоит дороже и не получает +50% XP.

## Спецпэты

В концепции есть три локационных спецпэта:

| Пэт | Локация | Эффект |
| --- | --- | --- |
| Тушканчик | Ржавые Пустоши | шанс найти шкатулки x3, иммунитет от ловушек |
| Капибара | Оазис | шанс найти шкатулки x2.5, иммунитет от ловушек |
| Барсук | Радиоактивная Пещера | шанс найти шкатулки x2, иммунитет от ловушек |

UX-правило: если спецпэт выбран в своей локации, его карточка должна явно подсвечивать бонус. Если этот пэт выбран в чужой локации, не надо намекать, что его суперспособность работает.

## Слоты

Слоты определяют, сколько пэтов можно отправить в XDV-рейды.

В текущей механике:

- без подписки слот-лимит идет по таблице грейда профиля;
- с подпиской слот-лимит примерно удваивается;
- USDT-рейды заявлены как режим без ограничений по слотам.

UX-правило для мобильного экрана:

- не показывать 14-22 слота сразу;
- показывать первые 4-6;
- остальные открывать через `Показать все слоты`;
- в USDT-режиме показывать `Без лимита`, но физически список все равно должен быть управляемым и прокручиваемым.

## Кумулятивный Эффект

Кумулятивный эффект, или стрик, растет от повторных отправок в одну и ту же локацию.

Правила:

- каждая отправка любого пэта в локацию дает +1%;
- один и тот же пэт не обязателен;
- разные пэты тоже увеличивают стрик;
- максимум зависит от локации;
- подписка и USDT не усиливают стрик;
- отправка в другую локацию сбрасывает накопленный эффект.

Капы:

| Локация | Максимум |
| --- | ---: |
| Ржавые Пустоши | +70% |
| Оазис | +50% |
| Радиоактивная Пещера | +30% |

Формула:

```text
Множитель = 1 + накопленный_процент

Ресурсы = базовое_количество x множитель
Шанс шкатулки = базовый_шанс x множитель
```

Пример:

```text
Оазис, стрик +35%
Базовая шкатулка 60%

60% x 1.35 = 81%
```

UX-правило: если отправка сбрасывает стрик другой локации, игрок должен увидеть предупреждение до подтверждения.

## XP

XP считается отдельно от ресурсов и шкатулок.

Порядок:

1. Берется базовый XP локации.
2. Если редкость пэта соответствует локации, применяется +50%.
3. Если рейд с подпиской, результат умножается на 2.
4. Если рейд USDT, результат умножается на 5.
5. Стрик не влияет на XP.

Пример:

```text
Оазис
Базовый XP: 500
Эпический пэт подходит: +50%
Режим: USDT x5

500 x 1.5 x 5 = 3750 XP
```

## Ресурсы

Обычные ресурсы зависят от локации.

| Локация | Главный ресурс | Вторичные ресурсы |
| --- | --- | --- |
| Пустоши | Патроны | Галаклеи |
| Оазис | Галаклеи | Патроны, Радиоактивные Желуди |
| Пещера | Радиоактивные Желуди | Патроны, Галаклеи |

Правила:

- ресурсы выдаются с разбросом 50%;
- стрик умножает обычные ресурсы;
- после умножения используется округление вниз;
- подписка и USDT не увеличивают обычные ресурсы, если не будет отдельного продуктового решения.

Пример:

```text
Пустоши
Патроны: 18
Стрик: +70%

18 x 1.7 = 30.6
Округление вниз = 30
```

## Шкатулки

Шкатулки считаются шансами по каждой редкости отдельно.

Порядок:

1. Берется базовый шанс шкатулки.
2. Применяется стрик.
3. Применяется множитель режима: x1, x2 или x4.
4. Применяется бонус спецпэта, если есть.
5. Шанс ограничивается капом 100%.
6. Если шкатулка выпала, отдельно проверяется крит.
7. Если крит сработал, количество этой шкатулки удваивается.

Пример:

```text
Оазис
Редкая шкатулка: 20%
Стрик: +50%
Подписка: x2

20% x 1.5 x 2 = 60%
```

Пещера может иметь шанс выше 100% до капа:

```text
Пещера
Базовая шкатулка: 80%
Стрик: +30%

80% x 1.3 = 104%
Кап = 100%
```

## Крит Шкатулки

Крит не дает новую категорию шкатулки. Он удваивает уже выпавшую шкатулку.

| Локация | Крит |
| --- | ---: |
| Ржавые Пустоши | 50% |
| Оазис | 25% |
| Радиоактивная Пещера | Нет |

UX-правило: в Пещере нельзя показывать активный блок крита. Нужно явно писать `Крит: нет`, чтобы игрок не ожидал удвоения.

## Особый Лут

Есть два новых ресурса:

- Ядро синтеза;
- Токен слота.

Ядро синтеза:

- выпадает в Пустошах и Оазисе;
- не выпадает в Пещере;
- базово 50% на 1 шт.;
- с подпиской 50% на 2 шт.;
- в USDT-рейде 50% на 5 шт., но только в локациях, где Ядро синтеза вообще выпадает.

Токен слота:

- выпадает только в Ржавых Пустошах;
- базово 50% на 1 шт.;
- с подпиской 50% на 2 шт.;
- в USDT-рейде 50% на 5 шт., но только в Ржавых Пустошах.

UX-правило: особый лут надо показывать даже при нулевом результате:

```text
Ядро синтеза: 0 шт. (шанс 50%)
Токен слота: 0 шт. (не выпадает в этой локации)
```

## Ловушки

Ловушки считаются после завершения рейда отдельно для каждого пэта.

Шансы:

| Локация | Без подписки | С подпиской | USDT |
| --- | ---: | ---: | ---: |
| Ржавые Пустоши | 5% | 0% | 0% |
| Оазис | 10% | 5% | 0% |
| Радиоактивная Пещера | 20% | 10% | 0% |

Если пэт попал в ловушку:

- он застревает в локации;
- запускается индивидуальный таймер 7 дней;
- выкуп или спасение доступны только пока таймер не истек;
- если таймер истек, пэт пропадает безвозвратно.

Формула выкупа:

```text
Выкуп = 3 x цена входа этого пэта в эту локацию
```

Примеры:

| Ситуация | Вход | Выкуп |
| --- | ---: | ---: |
| Редкий в Пустошах | 200 XDV | 600 XDV |
| Эпический в Оазисе | 400 XDV | 1200 XDV |
| Редкий в Оазисе | 800 XDV | 2400 XDV |
| Легендарный в Пещере | 800 XDV | 2400 XDV |
| Редкий в Пещере | 2400 XDV | 7200 XDV |

## Спасение Из Ловушки

Спасение - бесплатная альтернатива выкупу.

Правила:

- шанс успеха 50%;
- при успехе спасатель вытаскивает одного пэта;
- при провале спасатель тоже попадает в ловушку;
- один спасатель спасает одного пэта;
- можно пробовать несколько раз;
- если спасатель провалился, его выкуп считается от его собственной цены входа в эту локацию.

Пример:

```text
В ловушке Оазиса сидит легендарный пэт.
Его выкуп: 2400 XDV.

Игрок отправляет эпического спасателя.
Эпический пэт в Оазисе стоит 400 XDV.

Если спасатель провалится:
400 x 3 = 1200 XDV выкупа за спасателя.
```

## Уведомления

Для рейдов нужны уведомления, иначе длинный таймер и ловушки будут теряться.

Минимальный набор:

- рейд завершен;
- пэт попал в ловушку;
- таймер ловушки скоро истечет;
- спасатель успешно вытащил пэта;
- спасатель провалился и сам попал в ловушку;
- есть свободные слоты после завершения рейда.

Критичные уведомления:

- ловушка осталась меньше 24 часов;
- ловушка осталась меньше 1 часа;
- недостаточно XDV на выкуп.

## Пример Полного Сценария: Безопасный Фарм Пустошей

Игрок хочет стабильно фармить патроны и токены слота.

1. Открывает рейдовую карту.
2. Видит `Ржавые Пустоши +70%`.
3. Раскрывает Пустоши.
4. Выбирает базовый XDV-режим.
5. Выбирает редкого пэта.
6. Видит цену `200 XDV`.
7. Подтверждает отправку.
8. Через 24 часа получает XP, патроны, шанс Ядра синтеза, шанс Токена слота и шкатулки.
9. Если ловушки нет, нажимает `Повторить рейд`.

Почему это выгодно:

- дешево;
- риск низкий;
- стрик высокий;
- крит 50%;
- есть Токен слота.

## Пример Полного Сценария: Эпический Пэт В Оазисе

Игрок хочет качать эпического пэта и фармить галаклеи.

1. Открывает Оазис.
2. Видит скидку регулярности, если она есть.
3. Выбирает эпического пэта.
4. Цена для него `400 XDV`, потому что он подходит локации.
5. XP получает +50%.
6. В режиме подписки XP дополнительно умножается x2.
7. Шансы шкатулок в подписке умножаются x2.
8. Ловушка в подписке снижается с 10% до 5%.

Оазис - это маршрут для регулярного игрока: чем чаще туда ходить, тем важнее показать скидку и ее таймер сброса.

## Пример Полного Сценария: Пещера И USDT

Игрок хочет максимум XP и редкие шкатулки без риска потерять пэта.

1. Открывает Радиоактивную Пещеру.
2. Выбирает USDT-режим.
3. Видит цену `12 USDT`.
4. Видит `Ловушки 0%`.
5. Видит `XP x5`.
6. Видит `Шансы шкатулок x4`.
7. Отправляет легендарного пэта.

Результат:

- XP очень высокий;
- ловушек нет;
- шанс легендарной шкатулки увеличивается с 1% до 4%;
- Пещера все еще не имеет крита.

## Состояния Пэта В Рейдах

Для UI и backend удобно мыслить такими состояниями:

| Состояние | Что значит |
| --- | --- |
| `available` | Пэт доступен для отправки |
| `in_raid` | Пэт в активном рейде с таймером 24 или 12 часов |
| `raid_complete` | Рейд завершен, награды ждут получения |
| `trapped` | Пэт в ловушке, идет 7-дневный таймер |
| `rescuing` | Пэт отправлен спасателем |
| `lost` | Пэт потерян после истечения ловушки |
| `unavailable_pack` | Пэт недоступен из-за стаи |
| `unavailable_rent` | Пэт недоступен из-за аренды |

Минимальная схема:

```text
available
    |
    v
in_raid
    |
    +--> raid_complete --> available
    |
    +--> trapped
            |
            +--> ransom paid --> available
            |
            +--> rescue success --> available
            |
            +--> timer expired --> lost
```

## Что Должен Понимать Игрок

На каждом шаге интерфейс должен отвечать на один вопрос.

| Шаг | Вопрос игрока | Что показывает UI |
| --- | --- | --- |
| Главная карта | Куда идти? | 3 локации, стрик, риск, цена |
| Раскрытая локация | Что я получу? | XP, ресурсы, шкатулки, ловушка |
| Выбор режима | Чем отличается режим? | XDV, подписка, USDT и их бонусы |
| Выбор пэта | Кого выгодно отправить? | цена, редкость, подходит или нет |
| Подтверждение | Чем я рискую? | цена, 24ч/12ч, ловушка, сброс стрика |
| Активный рейд | Когда закончится? | таймер и прогресс |
| Итоги | Что выпало? | XP, ресурсы, шкатулки, особый лут |
| Ловушка | Что делать срочно? | 7 дней, выкуп, спасатель |

## Принятые Решения И Реализационные Риски

Ниже зафиксированы решения v1. Это уже не открытые вопросы для первого ТЗ, кроме backend-реализации и будущих балансных проверок.

### 1. DCR Не Используем

Проект пока не перешел на DCR, поэтому DCR не показывается в рейдовом интерфейсе и не участвует в расчетах.

В шапке можно показывать:

- XDV;
- USDT;
- игровые доллары как общий баланс приложения;
- уведомления;
- статус подписки при необходимости.

Слот-лимит не нужно объяснять через DCR. Игрок видит только количество доступных слотов.

### 2. Игровые Доллары Не Участвуют В Механике Рейдов

Игровые доллары в HUD не являются рейдовой валютой.

Источник правды по оплате и наградам:

- XDV используется для базовых рейдов и рейдов с подпиской;
- USDT используется для USDT-рейдов;
- выкуп из ловушки оплачивается в XDV;
- награды рейдов - XP, ресурсы, шкатулки, Ядро синтеза и Токен слота;
- игровые доллары не оплачивают вход, не выпадают как награда и не определяют слот-лимит.

Если позже игровые доллары должны стать валютой действий в рейдах, это нужно оформить отдельным продуктовым решением.

### 3. Ядро Синтеза И Токен Слота Остаются Локационными

Множители режима применяются только там, где ресурс вообще доступен в локации.

Правило:

- Ядро синтеза выпадает только в Пустошах и Оазисе;
- Токен слота выпадает только в Пустошах;
- в Пещере оба ресурса не выпадают;
- если ресурс недоступен в локации, UI показывает `0 / не выпадает`, а не общий шанс режима.

Пример: USDT-рейд в Пещере не дает `50% на 5 Токенов слота`, потому что Токен слота в Пещере не выпадает.

### 4. USDT Без Лимита Слотов Показываем Через Пакетный Список

USDT-рейды механически не имеют слот-лимита, но UI не должен рисовать бесконечную сетку.

Решение v1:

- в режиме USDT показывать `Без лимита слотов`;
- выводить пэтов партиями;
- добавлять кнопку `Добавить еще пэта`;
- технически использовать пагинацию или виртуальный список.

### 5. Спеш 2x - Это Автоматическая Длительность 12 Часов

`Спеш 2x` не является отдельной кнопкой, платным действием или ручным ускорителем.

Решение v1:

- базовый XDV-рейд длится 24 часа;
- XDV-рейд с подпиской длится 12 часов;
- USDT-рейд длится 24 часа;
- ускорение применяется при старте подписочного рейда;
- в слоте показывается индикатор `ускорение x2`, но не кнопка.

### 6. Стрик Сбрасывается При Успешном Старте Рейда В Другой Локации

Стрик хранится как привязка игрока к текущей локации.

Правило v1:

- отправка пэта в ту же локацию добавляет `+1%` к стрику этой локации;
- успешный старт рейда в другой локации сбрасывает стрик предыдущей локации;
- сброс происходит после успешной оплаты и создания рейда, а не просто после открытия подтверждения;
- активные рейды считают награды по snapshot-значению стрика на момент старта;
- массовый запуск в v1 разрешается только внутри одной локации.

UI перед подтверждением должен предупреждать: `Отправка в Оазис сбросит стрик Пустошей +70%`.

### 7. Скидка Оазиса Считается От Завершения Последнего Рейда

Скидка Оазиса работает только для XDV-рейдов.

Правило v1:

- цена считается при старте рейда от цены конкретного пэта в Оазисе;
- каждый следующий XDV-рейд в Оазис увеличивает скидку на 5%;
- минимальная цена - 50% от исходной цены;
- если в Оазисе есть активный рейд, скидка не сбрасывается;
- таймер сброса начинается от автоматического завершения последнего рейда в Оазисе;
- ручное получение награды не должно замораживать таймер;
- если за 7 дней после завершения игрок не запустил новый рейд в Оазис, скидка сбрасывается.

UI показывает:

```text
Скидка -15%
Сброс через 5д 12ч
```

### 8. Токен Слота Дает Постоянный XDV-Слот

Токен слота используется для постоянного расширения XDV-слотов.

Решение v1:

- 1 Токен слота тратится на +1 постоянный XDV-слот;
- максимум - 5 дополнительных токен-слотов на аккаунт;
- токен-слоты добавляются поверх таблицы грейда профиля и подписки;
- USDT-рейды токены не используют, потому что в USDT-режиме нет слот-лимита.

Формула:

```text
XDV-слоты = слоты по грейду профиля и подписке + разблокированные токен-слоты
```

### 9. Количество Шкатулок Ограничено Roll-Моделью

Для v1 отдельный глобальный quantity cap не нужен. Лимит задается самой моделью бросков.

Правило:

- каждая редкость шкатулки бросается один раз на каждого пэта в каждом рейде;
- шанс каждой редкости ограничивается 100%;
- если roll успешный, игрок получает 1 шкатулку этой редкости;
- если проходит крит, эта конкретная выпавшая шкатулка удваивается до 2 шт.;
- несколько пэтов считаются независимо.

Балансный риск остается: после тестов экономики можно добавить дневной или рейдовый лимит, если выдача окажется слишком высокой.

### 10. Статус Реализации В Ветке `feature/raids-mechanics`

Исторически в backend была старая voucher-модель рейдов. Новая механика этой ветки реализуется как отдельный домен `diaverseapi/app/raids`, а не как развитие старого пользовательского ваучера.

Backend v1 уже проектируется вокруг новых сущностей:

- каталог `raids_catalog.v1` с режимами, локациями, шансами, ценами, visual keys и таблицей слотов;
- профиль рейдов с внутренним `profile_grade` и количеством разблокированных token slots;
- активные и завершенные рейды с длительностью 24 или 12 часов;
- участники рейда и выбранные пэты;
- стрики по локациям;
- ловушки, выкуп и rescue attempt;
- payment order для USDT-старта;
- state endpoint для сборки всего экрана.

Frontend v1 уже привязан к этому контракту через same-origin BFF routes `/api/cabinet/raids/*` и экран `/{lang}/raids`.

Важные rollout-условия:

- backend должен быть включен флагом `RAIDS_WEB_ENABLED=true`;
- frontend должен быть включен флагом `NEXT_PUBLIC_RAIDS_WEB_ENABLED=true`;
- если frontend flag выключен, экран показывает fullscreen-состояние `Рейды готовятся`;
- если backend flag выключен, BFF вернет 503 и UI покажет состояние недоступности рейдов.

Эта ветка сохраняет продуктовые решения из гайда:

- DCR не используется;
- игровые доллары остаются только HUD-балансом;
- слот-лимит идет от внутреннего профиля рейдов и token slots;
- основная композиция не меняется: компактный HUD, центральная карта, раскрытая локация внутри карты, нижняя шторка выбора пэта.

## Рекомендованная Очередность Реализации

Чтобы не реализовывать все сразу хаотично, лучше идти слоями.

### Этап 1: Только Карта И Чтение Состояния

- экран рейдовой карты;
- три локации;
- HUD;
- раскрытие локации;
- моковые слоты;
- моковые шансы.

Цель: проверить UX и визуальную структуру.

### Этап 2: Базовый XDV-Рейд

- выбор пэта;
- цена XDV;
- запуск 24-часового базового XDV-рейда;
- таймер;
- завершение;
- базовые награды;
- без ловушек на первом техническом шаге или с простым шансом.

Цель: собрать основной игровой цикл.

### Этап 3: Стрики И Расчеты

- кумулятивный эффект;
- сброс при другой локации;
- шансы шкатулок;
- крит;
- ресурсы с округлением.

Цель: сделать экономику рейдов.

### Этап 4: Подписка И USDT

- XDV с подпиской;
- слоты подписки;
- автоматическая длительность 12 часов для XDV-рейда с подпиской;
- USDT-режим;
- отсутствие ловушек в USDT.

Цель: включить монетизацию и premium-различия.

### Этап 5: Ловушки И Спасение

- попадание в ловушку;
- 7-дневный таймер;
- выкуп;
- спасатель 50%;
- риск провала спасателя;
- уведомления.

Цель: добавить кризисную механику без ломания базового цикла.

### Этап 6: Полировка

- итоговые формулы в попапе;
- подсказки;
- предупреждение о сбросе стрика;
- скидка Оазиса;
- token slot flow;
- балансный cap шкатулок.

## Минимальный Набор Правил Для Первого Прототипа

Если нужно быстро собрать первый рабочий прототип, достаточно:

- 3 локации;
- 3 режима, но начать можно с базового XDV;
- выбор пэта;
- цена входа по локации и редкости;
- 24-часовой таймер для базового XDV-рейда;
- расчет XP;
- расчет ресурсов;
- расчет шкатулок;
- итоговое окно;
- без спасателей и сложной ловушки на самом первом шаге.

Но дизайн сразу должен предусматривать ловушки и USDT, чтобы потом не переделывать экранную архитектуру.
