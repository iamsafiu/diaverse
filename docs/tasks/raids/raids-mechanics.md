# Рейды "Путь к приключениям" — механика v5

[Back to Docs](../../README.md)

Дата исходной концепции: 25.05.2026  
Статус концепции: финальная концепция

Документ описывает новую механику рейдов Diaverse: 24-часовые базовые XDV/USDT-рейды, 12-часовые XDV-рейды с подпиской, кумулятивный эффект, цены по редкости пэтов, награды, шкатулки, ловушки и связи с другими игровыми системами.

## Коротко

- Базовые XDV-рейды и USDT-рейды длятся 24 часа, XDV-рейды с подпиской длятся 12 часов. После завершения пэтов нужно отправлять заново.
- Есть три уровня доступа: базовый XDV-рейд, XDV-рейд с подпиской и USDT-рейд.
- USDT-рейды одинаковы для всех игроков и не зависят от подписки.
- Кумулятивный эффект один для ресурсов и шансов шкатулок: +1% за каждую отправку пэта в одну и ту же локацию.
- Цена XDV-входа зависит от локации и редкости пэта.
- Подписка не даёт скидку на XDV-вход и не влияет на USDT-рейды.
- Ловушки считаются отдельно для каждого пэта после завершения рейда.
- Механика переносится из Telegram-бота в приложение.

## UI/UX структура мобильного интерфейса

Основной формат рейдов — мобильный полноэкранный игровой экран 9:16. Центральную часть занимает большая рейдовая карта с тремя локациями. Это не таблица и не магазинная витрина, а игровой рабочий экран: игрок выбирает локацию, режим рейда, слот и пэта.

### Базовая логика интерфейса

```text
Главный экран
  -> выбор локации
  -> раскрытая локация
  -> выбор режима рейда
  -> выбор слота
  -> нижняя шторка пэтов
  -> подтверждение отправки
  -> слот с таймером 24 или 12 часов
  -> итоги рейда или ловушка
```

Принципы:

- Основная часть экрана всегда работает как большая вертикальная рейдовая карта.
- На главном экране видны три крупные карточки локаций: Ржавые Пустоши, Оазис и Радиоактивная Пещера.
- Детальные шансы, режимы доступа и сетка слотов показываются только после выбора локации.
- В шапке пока не показывать DCR: продукт еще не перешел на DCR. HUD может показывать XDV, USDT и общий баланс игровых долларов, но игровые доллары не используются как рейдовая валюта.
- Режимы `Базовый`, `С подпиской` и `USDT` не нужно дублировать на каждой свернутой карточке. Их лучше показывать внутри раскрытой локации.
- Если доступных слотов много, на мобиле не показывать все 14-22 слота сразу. Сначала показывать первые 4-6 слотов и действие `Показать все слоты`.

### Визуальный стиль

- Общая тема: темный футуристичный кибер-интерфейс.
- Основной фон: глубокий графитовый или антрацитовый.
- Ржавые Пустоши: ржаво-оранжевый, янтарный, песочный свет.
- Оазис: бирюзовый, изумрудный, водный свет.
- Радиоактивная Пещера: кислотно-зеленый основной акцент, фиолетовый вторичный акцент.
- Карточки локаций: темные полупрозрачные панели с тонкой цветной рамкой биома.
- Ловушка: отдельный кризисный стиль, темно-бордовый фон, красная рамка, крупный таймер.

### Экран 1: главная рейдовая карта

На первом экране игрок видит общий статус и три локации. Цель экрана — быстро выбрать, куда отправлять пэтов.

```text
+--------------------------------+
| XDV 12 450   USDT 18.5     bell|
| $ 84 200                 crown |
+--------------------------------+
|                                |
|          РЕЙДОВАЯ КАРТА        |
|                                |
| +----------------------------+ |
| | РЖАВЫЕ ПУСТОШИ             | |
| | +70% стрик    ловушка 5%   | |
| | 200 XDV       [пэт][+]     | |
| +----------------------------+ |
|                                |
| +----------------------------+ |
| | ОАЗИС                      | |
| | +35% стрик    ловушка 10%  | |
| | 400/800 XDV   [пэт][пэт]   | |
| +----------------------------+ |
|                                |
| +----------------------------+ |
| | РАДИОАКТИВНАЯ ПЕЩЕРА       | |
| | +12% стрик    ловушка 20%  | |
| | 800/2400 XDV  [+]          | |
| +----------------------------+ |
|                                |
+--------------------------------+
| Магазин  Фабрика  Рейды  Проф |
+--------------------------------+
```

Свернутая карточка локации показывает только:

- название локации;
- текущий кумулятивный эффект;
- риск ловушки для текущего базового XDV-режима;
- короткую цену XDV;
- мини-слоты занятых пэтов.

При нажатии выбранная локация занимает основную часть экрана. Остальные локации остаются снизу в виде коротких полосок для быстрого переключения.

```text

|                                |
| Шкатулки:                      |
| Базовая       60% -> 81%       |
| Необычная     40% -> 54%       |
| Редкая        20% -> 27%       |
| Эпическая     10% -> 13.5%     |
|                                |
| Опасность:                     |
| Ловушка 10%       Крит 25%     |
|                                |
| Слоты:                         |
| +----------+  +----------+     |
| | пэт      |  | +        |     |
| | 12ч      |  | выбрать  |     |
| +----------+  +----------+     |
| +----------+  +----------+     |
| | +        |  | +        |     |
| +----------+  +----------+     |
|                                |
| Ржавые Пустоши                 |
| Радиоактивная Пещера           |
+--------------------------------+
| Магазин  Фабрика  Рейды  Проф |
+--------------------------------+
```

Правила раскрытой локации:

- Переключатель режима находится внутри раскрытой локации.
- Для шкатулок показывать базовый шанс и итоговый шанс с учетом кумулятивного эффекта и режима.
- Для крита шкатулки показывать процент из backend. Если значение `0%`, показывать `Нет`.
- Для USDT-режима явно показывать `Ловушки 0%` и `Без лимита слотов`.

### Экран 3: выбор пэта в нижней шторке

Шторка открывается после нажатия на пустой слот. Фон локации затемняется, игрок выбирает пэта из списка.

```text
+--------------------------------+
| ОАЗИС                    +35%  |
|                                |
| [слоты и параметры затемнены]  |
|                                |
+--------------------------------+
|          ВЫБРАТЬ ПЭТА          |
| [Редкие] [Эпические] [Легенд.] |
|                                |
| +----------------------------+ |
| | Тушканчик          800 XDV | |
| | доступен          бонус локации | |
| +----------------------------+ |
| +----------------------------+ |
| | Капибара           400 XDV | |
| | доступен       подходит ok | |
| +----------------------------+ |
| +----------------------------+ |
| | Барсук             800 XDV | |
| | в другом рейде             | |
| +----------------------------+ |
|                                |
| [Отмена]                       |
+--------------------------------+
```

Карточка пэта в шторке должна показывать:

- имя и аватар пэта;
- редкость;
- цену входа, уже пересчитанную под выбранную локацию и редкость пэта;
- доступность: доступен, в другом рейде, в стае, в аренде, в ловушке;
- подсветку подходящего пэта, если редкость пэта совпадает с локацией и дает +50% XP.

### Экран 4: подтверждение отправки

После выбора пэта показывается короткое подтверждение с ценой, длительностью и рисками.

```text
+--------------------------------+
| Отправить Капибару в Оазис?    |
|                                |
| Режим: Базовый XDV             |
| Цена: 400 XDV                  |
| Длительность: 24 часа          |
| Ловушка: 10%                   |
| Крит шкатулки: 25%             |
|                                |
| [Отправить]                    |
| [Отмена]                       |
+--------------------------------+
```

Если выбран USDT-режим, подтверждение показывает цену в USDT и `Ловушка: 0%`.

### Экран 5: пэт в рейде

После отправки слот становится занятым и показывает прогресс рейда. Для базового XDV и USDT это 24 часа, для XDV с подпиской - 12 часов.

```text
+--------------------------------+
| ОАЗИС                    +35%  |
|                                |
| Слоты:                         |
| +----------------+ +--------+  |
| | Капибара       | | +      |  |
| | 12ч 18м        | | выбрать|  |
| | progress bar   | +--------+  |
 | | ускорение x2   |             |
| +----------------+             |
|                                |
| Ржавые Пустоши                 |
| Радиоактивная Пещера           |
+--------------------------------+
| Магазин  Фабрика  Рейды  Проф |
+--------------------------------+
```

Правила:

- Для рейда с подпиской не показывать отдельную кнопку `Спеш 2x`: ускорение применяется автоматически при старте.
- Базовый XDV-рейд и USDT-рейд длятся 24 часа.
- XDV-рейд с подпиской длится 12 часов.
- Таймер всегда считает фактическое оставшееся время до завершения рейда.

### Экран 6: ловушка

Если пэт попал в ловушку, слот превращается в кризисную карточку. Игрок должен сразу видеть срок до потери пэта и варианты спасения.

```text
+--------------------------------+
| ОАЗИС                ЛОВУШКА   |
+--------------------------------+
|                                |
| +----------------------------+ |
| | Капибара заблокирована     | |
| | Осталось: 6д 23ч 59м       | |
| |                            | |
| | Выкуп: 1200 XDV            | |
| |                            | |
| | [Выкупить за 1200 XDV]     | |
| | [Отправить спасателя 50%]  | |
| +----------------------------+ |
|                                |
| Остальные слоты:               |
| +----------+  +----------+     |
| | +        |  | пэт      |     |
| +----------+  +----------+     |
+--------------------------------+
| Магазин  Фабрика  Рейды  Проф |
+--------------------------------+
```

Кризисный UI должен показывать:

- имя заблокированного пэта;
- локацию ловушки;
- таймер до безвозвратной потери;
- сумму выкупа;
- действие выкупа;
- действие отправки спасателя с шансом успеха 50%.

### Экран 7: выбор спасателя

После нажатия `Отправить спасателя 50%` открывается шторка выбора пэта. Вверху обязательно показывается риск провала.

```text
+--------------------------------+
| ОТПРАВИТЬ СПАСАТЕЛЯ            |
|                                |
| Шанс успеха: 50%               |
```

Для каждого спасателя нужно показывать его собственную цену выкупа при провале, потому что она зависит от цены входа этого спасателя в текущую локацию.

После завершения рейда показывается модальное окно итогов. Игрок должен понимать, что именно получил и почему.

```text
|                                |

|                                |
```

Итоги должны показывать:

- XP с учетом бонуса редкости и режима доступа;
- обычные ресурсы с учетом кумулятивного эффекта;
- выпавшие шкатулки;
- крит шкатулки, если он сработал;
- Ядро синтеза и Детали токена слота, включая нулевой результат;
- кнопку повторного запуска, потому что рейд после 24 часов не перезапускается автоматически.

## Термины

| Термин | Значение |
| --- | --- |
| Пэт | Игровой питомец, которого игрок отправляет в рейд |
| Локация | Одна из трёх рейдовых зон: Ржавые Пустоши, Оазис, Радиоактивная Пещера |
| XDV-рейд | Рейд с оплатой входа токеном XDV |
| USDT-рейд | Рейд с оплатой входа в USDT, без подписочных зависимостей |
| Кумулятивный эффект | Накопительный множитель к ресурсам и шансам шкатулок |
| Шкатулка | Случайная награда с отдельным шансом выпадения по редкости |
| Крит шкатулки | Шанс удвоить количество уже выпавшей шкатулки |
| Ловушка | Негативное событие, из-за которого пэт застревает в локации на срок до 7 дней |
| Грейд профиля | Внутренний показатель, определяющий количество доступных слотов для XDV-рейдов. Не является DCR или игровой валютой |

## 2. Общие правила расчёта

### 2.1. Длительность и повторный запуск

- Базовый XDV-рейд и USDT-рейд длятся 24 часа.
- XDV-рейд с подпиской длится 12 часов: это автоматическое ускорение x2, а не отдельная кнопка или повторное платное действие.
- После завершения рейда игрок вручную отправляет пэтов в новый рейд.
- Других длительностей в текущей концепции нет.

### 2.2. XP

Порядок расчёта XP:

1. Берётся базовый XP локации.
2. Если редкость пэта соответствует локации, применяется бонус +50%.
3. Если рейд с подпиской, итоговый XP умножается на 2.
4. Если рейд USDT, итоговый XP умножается на 5.
5. Кумулятивный эффект на XP не влияет.

### 2.3. Ресурсы

- Базовые ресурсы локации выдаются с разбросом 50%.
- Кумулятивный эффект умножает количество ресурсов.
- Для целочисленного количества ресурсов используется округление вниз после умножения.
- Подписка и USDT в текущей концепции не увеличивают обычные ресурсы локации. Они увеличивают XP, шансы шкатулок и количество новых ресурсов: Ядра синтеза и Токена слота.

### 2.4. Шкатулки

Порядок расчёта шкатулки:

1. Берётся базовый шанс шкатулки.
2. Применяется кумулятивный эффект.
3. Применяется множитель доступа: x1, x2 или x4.
4. Применяются специальные множители пэтов, если они активны.
5. Шанс ограничивается капом 100%.
6. Если шкатулка выпала, отдельно рассчитывается крит шкатулки.
7. Если крит прошёл, количество этой шкатулки удваивается.

Для v1 каждая редкость шкатулки бросается один раз на каждого пэта в каждом рейде. Базовое количество выпавшей шкатулки — 1 шт.; крит может увеличить его до 2 шт. Дополнительного quantity cap сверх этой модели не требуется до отдельного балансного теста.

## 3. Кумулятивный эффект

Кумулятивный эффект — единая механика, которая одновременно усиливает:

- количество обычных ресурсов локации;
- шансы выпадения шкатулок.

### 3.1. Накопление

| Локация | Прирост | Максимум |
| --- | ---: | ---: |
| Ржавые Пустоши | +1% за отправку пэта | +70% |
| Оазис | +1% за отправку пэта | +50% |
| Радиоактивная Пещера | +1% за отправку пэта | +30% |

Правила:

- Каждая отправка любого пэта в локацию даёт +1%.
- Неважно, отправляется один и тот же пэт или разные пэты.
- Если игрок запускает рейд в другой локации, накопленный эффект предыдущей локации сбрасывается после успешной оплаты и старта рейда.
- Подписка и USDT не увеличивают кумулятивный эффект.
- Награды уже запущенного рейда считают кумулятивный эффект по snapshot-значению на момент старта и не меняются, если игрок позже переключился на другую локацию.
- В v1 массовый запуск разрешается только внутри одной локации. Если позже появится массовый запуск в разные локации, backend должен обрабатывать такие старты последовательно и явно показывать игроку сброс стрика.

### 3.2. Формула

```text
Множитель = 1 + накопленный_процент

Ресурсы = базовое_количество x множитель
Шанс шкатулки = базовый_шанс x множитель
```

### 3.3. Примеры

| Локация | Эффект | Пример ресурса | Пример шкатулок |

### 8.2. Что происходит в ловушке

- Пэт застревает в локации.
- Для этого пэта запускается индивидуальный таймер на 7 дней.
- Таймеры разных пэтов идут параллельно и независимо.
- Если через 7 дней пэт не выручен, он пропадает безвозвратно.
- Выкуп или спасение возможны только пока таймер не истёк.

### 8.3. Способ 1: выкуп за XDV

```text
Стоимость выкупа = 3 x цена входа этого пэта в эту локацию
```

Выкупить можно в любой момент и любое количество пэтов сразу.

| Пэт и локация | Цена входа | Выкуп |
| --- | ---: | ---: |
| Редкий в Пустошах | 200 XDV | 600 XDV |
| Эпический в Пустошах | 200 XDV | 600 XDV |
| Эпический в Оазисе | 400 XDV | 1200 XDV |
| Редкий в Оазисе | 800 XDV | 2400 XDV |
| Легендарный в Пещере | 800 XDV | 2400 XDV |
| Редкий в Пещере | 2400 XDV | 7200 XDV |
| Эпический в Пещере | 2400 XDV | 7200 XDV |

### 8.4. Способ 2: отправка пэта на выручку

- Отправка на выручку бесплатна, плата за вход не взимается.
- Шанс успеха: 50%.
- При успехе спасатель вытаскивает одного пэта.
- При провале спасатель сам попадает в ловушку.
- Один пэт спасает только одного пэта.
- Отправлять на выручку можно сколько угодно раз.
- Если спасатель проваливается, его выкуп зависит от его собственной цены входа в эту локацию, а не от цены спасаемого пэта.

Пример:

- В ловушке Оазиса сидит легендарный пэт. Его вход стоил 800 XDV, выкуп стоит 2400 XDV.
- Игрок отправляет на выручку редкого пэта. Отправка бесплатна.
- Если редкий пэт провалится, его цена входа в Оазис равна 800 XDV, поэтому его выкуп стоит 2400 XDV.
- Если бы игрок отправил эпического пэта, его цена входа в Оазис была бы 400 XDV, а выкуп стоил бы 1200 XDV.

Если в ловушке несколько пэтов:

- При успехе спасатель вытаскивает одного из них.
- При провале спасатель присоединяется к застрявшим.
- Каждый пэт сохраняет собственный 7-дневный таймер.

## 11. Связи с другими системами

| Система | Связь с рейдами |
| --- | --- |
| Грейд профиля | Определяет количество слотов для XDV-рейдов |
| Редкость пэта | Влияет на цену входа и бонус к XP в соответствующей локации |
| Рейдовые пэты | Локационные питомцы усиливают назначенный ресурс, шкатулки или XDV-вход |
| Подписки | Дают x2 к XP, x2 к шкатулкам, автоматическую длительность 12 часов, больше слотов, больше новых ресурсов и меньше ловушек |
| USDT-рейды | Дают x5 к XP, x4 к шкатулкам, больше новых ресурсов, без лимита слотов и без ловушек |
| Ядро синтеза | Используется для эволюции, мутаций и крафта |
| Детали токена слота | Выпадает как компонент для фабричной механики; слоты в рейдах не открывает |
| Стая | Пэты в рейде недоступны для стаи |
| Аренда | Пэты в рейде недоступны для аренды |
| Фабрика | Ресурсы из рейдов используются в цехах |

## 12. Монетизация

### 12.1. Подписка

Подписка усиливает эффективность XDV-рейдов:

- x2 к шансам шкатулок;
- x2 к XP;
- +100% к количеству новых ресурсов;
- автоматическое ускорение рейда до 12 часов;
- больше слотов;
- шанс ловушки уменьшается вдвое или становится 0% для Пустошей.

Подписка не даёт скидок на XDV-вход и не влияет на USDT-рейды.

### 12.2. USDT-рейды

USDT-рейды одинаковы для всех:

- x4 к шансам шкатулок;
- x5 к XP;
- +400% к новым ресурсам;
- без ограничений по слотам;
- без ловушек;
- подписка не влияет.

### 12.3. Экономические мотиваторы

- Чем выше грейд профиля, тем больше XDV-слотов.
- Правильный пэт в правильной локации получает базовую цену и +50% XP.
- Ловушки создают мотивацию для подписки и для выбора подходящих пэтов, потому что выкуп считается от цены входа.
- USDT-рейды дают максимальную эффективность без ловушек и без слот-лимита.

## 13. Риски баланса

| Риск | Почему важно | Решение |
| --- | --- | --- |
| Пустоши могут стать слишком прибыльными | +70% к шансам шкатулок и крит 50% усиливают регулярный фарм | Тестировать экономику и корректировать шансы |
| Крит и кумулятивный эффект могут разгонять лут | Комбинация множителей может дать слишком много шкатулок | Ввести потолок количества шкатулок за рейд |
| Баланс ROI между биомами | Рост сырой награды не гарантирует рост выгоды на XDV | Отслеживать экономику регулярных рейдов |
| Потеря пэтов в ловушках | Free-to-play игроки могут потерять пэтов при невыкупе | Пустоши почти безопасны, подписка снижает риск |
| UX-сложность | Много правил на локацию и уровень доступа | Нужны понятные иконки, подсказки и сравнение локаций |

## 14. Вопросы для реализации

| Вопрос | Текущее решение в документе |
| --- | --- |
| Округление ресурсов после множителей | Использовать округление вниз |
| Кап шансов шкатулок | Ограничивать шанс 100% |
| Кап количества шкатулок | В v1 каждая редкость бросается один раз на пэта; крит удваивает выпавшую шкатулку до 2 шт. |
| Порядок множителей киберпэтов | Применять после кумулятивного эффекта и доступа, перед капом 100% |
| Кумулятивный эффект на Ядро синтеза и Детали токена слота | Не применять |
| Отображение DCR в мобильном UI | DCR не показывать. Игровые доллары допустимы только как общий HUD-баланс, не как рейдовая валюта |
| Старые значения слотов | Использовать таблицу грейда профиля из раздела 5 |
| Спеш 2x | Не кнопка. Для XDV-рейда с подпиской длительность сразу 12 часов |
| Сброс стрика | При успешном старте рейда в другой локации; активные рейды используют snapshot стрика на момент старта |
| Детали токена слота | Выпадает в Пустошах и Пещере; не тратится на рейдовые слоты |

## 15. Реализационный контракт v1

Эта секция фиксирует, как продуктовая механика привязана к реализации в ветке `feature/raids-mechanics`.

### 15.1. Backend API

Backend-модуль новой механики живет в `diaverseapi/app/raids` и подключается в общий v1-router с префиксом `/v1/cabinet/raids`.

Действующие endpoint names:

| Метод | Endpoint | Назначение |
| --- | --- | --- |
| `GET` | `/v1/cabinet/raids/catalog` | Каталог режимов, локаций, шансов, цен, visual keys и таблицы слотов |
| `GET` | `/v1/cabinet/raids/state` | Игровое состояние пользователя: HUD-балансы, профиль, слоты, рейды, ловушки, пэты, уведомления |
| `POST` | `/v1/cabinet/raids/runs/start` | Старт рейда с idempotency key, локацией, режимом и списком пэтов |
| `POST` | `/v1/cabinet/raids/runs/{run_id}/claim` | Получение результата завершенного рейда |
| `POST` | `/v1/cabinet/raids/traps/{trap_id}/ransom` | Выкуп пэта из ловушки за XDV |
| `POST` | `/v1/cabinet/raids/traps/{trap_id}/rescue` | Отправка пэта-спасателя с шансом 50% |

Все command endpoints возвращают единый `RaidCommandResponse`: статус, idempotency key, возможный обновленный state, payment order для USDT-старта, уведомления и ошибки. Все private responses должны быть `no-store`.

### 15.2. Frontend и BFF

Веб-экран расположен в `diaweb/frontend/app/[lang]/(cabinet)/raids/page.tsx` и открывается как `/{lang}/raids`.

Same-origin BFF routes повторяют backend-контракт под `/api/cabinet/raids`:

| Frontend route | Backend target |
| --- | --- |
| `/api/cabinet/raids/catalog` | `/v1/cabinet/raids/catalog` |
| `/api/cabinet/raids/state` | `/v1/cabinet/raids/state` |
| `/api/cabinet/raids/runs/start` | `/v1/cabinet/raids/runs/start` |
| `/api/cabinet/raids/runs/{runId}/claim` | `/v1/cabinet/raids/runs/{run_id}/claim` |
| `/api/cabinet/raids/traps/{trapId}/ransom` | `/v1/cabinet/raids/traps/{trap_id}/ransom` |
| `/api/cabinet/raids/traps/{trapId}/rescue` | `/v1/cabinet/raids/traps/{trap_id}/rescue` |

BFF обязан прокидывать cookie, `Accept-Language`, `X-TimeZone`, `X-Telegram-WebApp-Platform`, `X-Request-ID` и возвращать `Cache-Control: no-store`.

### 15.3. Feature flags

Для включения полного веб-сценария нужны два флага:

- backend: `RAIDS_WEB_ENABLED=true`;
- frontend: `NEXT_PUBLIC_RAIDS_WEB_ENABLED=true`.

Если frontend flag выключен, `/raids` показывает fullscreen rollout-disabled state и не рендерит карту. Если backend flag выключен, BFF получает 503 `RaidUnavailableResponse`.

### 15.4. UI guardrails

Композиция реализации должна оставаться такой же, как в этом ТЗ:

- экран полноэкранный и mobile-first;
- HUD компактный и показывает XDV, USDT и игровые доллары;
- DCR нигде не показывается;
- игровые доллары остаются только HUD-балансом и не участвуют в рейдовой экономике;
- центральная часть экрана — большая рейдовая карта;
- свернутые локации, раскрытая локация, слоты, подтверждение, результат и ловушки живут внутри этой карты;
- выбор пэта открывается нижней шторкой поверх карты;
- режимы `Базовый`, `С подпиской`, `USDT` показываются в раскрытой локации, а не на каждой свернутой карточке;
- локальные таймеры тикают на клиенте и не должны запускать per-second refetch состояния.
