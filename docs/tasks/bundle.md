# Bundle Task Brief

📦 Доработка карточек бандлов

КАРТОЧКА БАНДЛА — ВИЗУАЛЬНЫЕ ИЗМЕНЕНИЯ

Убрать звёздочку в правом верхнем углу (содержимое бандлов разнородное, усреднённая оценка не актуальна)

Убрать кнопку «Примерить» снизу карточки

Оставить без изменений: кнопка «Подробности» в левом верхнем углу, отображение цены

КНОПКА «Подробности» (левый верхний угол)

Кнопка должна наконец начать работать. Сейчас по клику ничего не происходит.

Новое поведение: по клику карточка переворачивается с анимацией (flip), открывая оборотную сторону.

На обороте — текстовое описание содержимого бандла:

название каждой сущности

эволюция (для питомцев)

количество

Повторный клик (или отдельная кнопка «назад») возвращает карточку в исходное положение.

Дизайн оборотной стороны — любой временный, будет переработан отдельно.

ИНТЕРФЕЙС СОДЕРЖИМОГО БАНДЛА

Вместо текущего способа отображения содержимого — добавить поле загрузки изображения:

загрузка произвольной картинки (upload)

отображение загруженной картинки внутри карточки

БЕЙДЖ «ВЫГОДА» — замена кнопки «Примерить»

На место кнопки «Примерить» добавить бейдж:

  [ 34% выгода ]

Знак «минус» не отображается

Процент рассчитывается автоматически при сохранении бандла

ЛОГИКА РАСЧЁТА ПРОЦЕНТА ВЫГОДЫ

Идея: сравнить, сколько стоили бы все сущности из бандла при покупке по отдельности (по магазинным ценам), с фактической ценой бандла. Разница в процентах — это выгода. При расчёте учитывать количество каждой сущности.

ОСОБЫЙ СЛУЧАЙ — ПИТОМЦЫ С ЭВОЛЮЦИЯМИ

Если в бандл добавлен питомец не первой эволюции, его стоимость считается через цену базового питомца (1-я эволюция) с множителем:

  4-я эволюция → ×27
  5-я эволюция → ×81
  6-я эволюция → ×243

вставляться будет примерно это ^^^^^ в каждый бандл - своё.
