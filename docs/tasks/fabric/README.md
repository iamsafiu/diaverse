## Правила Работы

- Markdown-файлы считаются рабочими readable copies, а исходные `.doc` сохраняются как полученные артефакты.
- Если меняется механика, обновлять сначала `factory-mechanics-final.md`, затем дизайнерское ТЗ.
- Таблицы должны оставаться pipe-таблицами Markdown, чтобы их могли читать Git, IDE, GBrain и AI agents.
